# Vease App 官方界面版宣传图

本版替代上一版 AI 场景海报。三张 1200 × 1600 竖图使用同一套官网视觉：白底、系统字体、细灰边框、紫色点缀，直接复用 `public/favicon.svg` 官方 Logo 及 `src/assets/product-screen-{1,2}.jpg` 产品截图。没有生成的场景、设备或界面。

PNG 可直接发布；SVG 内嵌原始截图，保留文字、Logo、边框等可编辑元素。`copy.json` 集中管理少量文案，执行 `python3 render.py` 可重导出（需要 rsvg-convert）。渲染脚本从本仓库读取品牌与截图素材；SVG 独立携带素材，可单独交付。

截图来自 2026-10-23 的实际 React 组件与本地示例项目，并非生产验证或真实 AI 运行结果；第 2、3 张展示原始截图局部，未重新绘制 UI。出处和照片来源见 `src/assets/README.md`。图中标注「示例项目界面」。全套无域名、二维码和下载链接；保留 Vease App、macOS Apple Silicon 与邀请内测说明。

三种版式：01 居中产品封面，完整工作台与三步概览；02 浅灰卡片版，放大镜头素材库；03 左对齐编辑导读，放大反馈界面并附引用式文案。
